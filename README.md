# 🎂 Gâteaux de Saris

Sitio web oficial de **Gâteaux de Saris** — Pasteles caseros elaborados con pasión e ingredientes de alta calidad.

🌐 **Sitio en vivo:** [https://loursanz.github.io/gateaux-de-saris/](https://loursanz.github.io/gateaux-de-saris/)

---

## ✨ Características

- Catálogo de pasteles con fotografías reales
- Diseño elegante y responsive (se ve bien en celular y computadora)
- Cambio de idioma: **Español / English / Français**
- Botones de pedido conectados a WhatsApp
- Sección "Sobre Nosotros"
- Enlaces a Instagram y WhatsApp
